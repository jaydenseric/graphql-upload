# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 18.x    | :white_check_mark: |
| < 18.0  | :x:                |

## Reporting a Vulnerability

Please do not open a public GitHub issue for security vulnerabilities.  
Instead, report it privately using GitHub's [private vulnerability reporting](../../security/advisories/new) feature for this repository, if enabled. If it is not enabled, please open a regular issue requesting a private channel and a maintainer will follow up. 
You can expect an initial response within 7 days. If the vulnerability is confirmed, we will work with you on a fix and coordinate a disclosure timeline before any public advisory is published. If declined, we will explain why. 
Only 18.x is listed as supported since that's the current major (checked your cloned copy's package.json), adjust if the maintainer actually still patches older majors.
